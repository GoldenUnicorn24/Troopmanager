## Signieren und Aktualisieren

Die Debug-APK ist eine Testversion mit Android-Debug-Zertifikat. Die Release-APK enthält keinen neuen Produktionsschlüssel. Sie muss außerhalb des Repositorys mit dem bisherigen Updateschlüssel signiert werden, bevor sie eine bestehende Installation aktualisieren kann:

```sh
apksigner sign --ks /pfad/zum/bisherigen-update.keystore --out Troopmanager-v0.65.0.apk Troopmanager-v0.65.0-release-unsigned.apk
apksigner verify --verbose Troopmanager-v0.65.0.apk
```

Das Passwort interaktiv eingeben; Schlüssel und Passwort bleiben außerhalb von Git. Keine Kampagnendaten löschen, um einen Zertifikatswechsel zu umgehen. Keine Geräteprofiling- oder manuelle Hardwaretestkampagne durchgeführt, entsprechend der Vorgabe.
