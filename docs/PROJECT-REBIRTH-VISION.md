# Project Rebirth – Vision

> „Ich begann als einfacher junger Söldner mit wenig Geld. Ich verbrachte den ersten Abend in einer Taverne, lernte verschiedene Menschen kennen, trank, gewann ein Würfelspiel und traf eine interessante Kriegerin. Wir waren anfangs nur Bekannte. …“

Troopmanager soll sich nicht länger wie ein Verwaltungsprogramm mit Fantasy-Bildern anfühlen, sondern wie ein Leben in einer Welt, in der Königreiche auch ohne dich Krieg führen.

## Zwei Ebenen, eine Welt

| Ebene A – persönliches Rollenspiel | Ebene B – Strategie |
|---|---|
| Begehbare Orte (zuerst die Taverne), Gespräche, Freundschaft, Rivalität, Romanze, Arbeit, Reisen | Kronlande-Karte, Provinzen, Heere, Handel, Diplomatie, Belagerungen, Dynastie |
| `LifeState`, `NpcIdentity`, `DialogueEngine`, `TavernEngine` | `CrownState`, `WorldEngine`, `CrownEngine` … (unverändert) |

Beide lesen und schreiben **dieselben Kronprovinzen**. Ein Überfall auf Rabenfurt, von dem die Taverne erzählt, ist derselbe, den die Karte zeigt; die Preise in Rabenfurt steigen, Söldnerwerber tauchen auf.

## Spielmodi

| Modus | Start | Akte |
|---|---|---|
| Sandbox | Jede Herkunft (auch Adelserbe, Händler), wählbares Vermögen, ohne Land | aus |
| Freies Leben | Gewöhnliche Herkunft (Dorf, Söldner, Jäger …), wenig Geld | aus |
| Grenzherr | Klassischer Start: Festung, Gebiet, Armee | zuschaltbar |
| Geschichte | Klassischer Start mit den drei Akten und Bossen | an |

## Aufstieg

Gewöhnlicher Bürger → Rekrut → Soldat / Söldner → Hauptmann → Kommandant → (Lehnseid) Burgherr → König. Ruf wächst durch Aufträge, Schlichten, Schlägereien, Feldzüge. Mit Ruf 150 und 800 Gold kann die Grenzfeste übernommen werden – ab dann gilt das vollständige Strategiespiel auf dem bis dahin gelebten Weltzustand.

## Menschen statt Menükarten

Jede wichtige Person hat Namen, Gesicht, Persönlichkeit (Wärme, Wagemut, Ehre, Humor, Neugier, Temperament), Interessen, Vorlieben, ein Ziel, eine Tagesroutine und Erinnerungen an dich. Sie kann dich mögen, dir misstrauen, Nein sagen und Grenzen setzen. Die beim Start gestaltete Gefährtin ist eine solche Person – keine garantierte Ehefrau.

## Leitplanken

- Offline, keine Online-Pflicht, kein Pay-to-Win.
- Bestehende Grenzherr-Spielstände bleiben spielbar.
- Erwachsene, einvernehmliche Beziehungen; Intimität nur angedeutet (Fade-to-Black).
- Keine vorgetäuschte Grafikqualität.
